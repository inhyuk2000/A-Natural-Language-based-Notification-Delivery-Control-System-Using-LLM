# 1. Project Overview (프로젝트 개요)

- **프로젝트 이름**: LLM을 활용한 자연어 기반 알림 전송 제어 시스템 개발
- **프로젝트 기간**: 2025.07 ~ 2025.11
- **프로젝트 설명**: 사용자의 자연어 명령에서 알림 수신 조건과 대상을 추출하고, 조건에 맞는 알림만 선별적으로 전송하는 LLM 기반 모바일 알림 제어 시스템
- **프로젝트 목적**: 복잡한 수동 설정 과정과 머신러닝 기반 자동 예측의 부정확성을 개선하여 사용자가 자연어만으로 원하는 알림 수신 조건을 설정할 수 있도록 지원
- **데이터 출처**: 사용자 7명으로부터 수집한 자연어 명령 시나리오 24개
- **주요 설계 대상**: 시간·장소·활동을 나타내는 조건 필드와 앱·키워드를 나타내는 대상 필드
- **프로젝트 성과**: KSC 2025 논문 발표 및 Paper Accept

# 3. Key Features (주요 기능)

- **자연어 기반 알림 조건 설정**
  - 사용자가 원하는 알림 수신 조건을 자연어로 입력할 수 있습니다.
  - 복잡한 설정 메뉴 없이 대화형 인터페이스를 통해 조건을 설정합니다.

- **LLM 기반 조건 추출**
  - ChatGPT 4o-mini의 Function Calling을 활용해 자연어 명령을 구조화합니다.
  - 시간, 장소, 활동 등의 조건과 앱, 키워드 등의 알림 대상을 JSON 형태로 추출합니다.

- **구조화된 JSON 스키마**
  - 사용자 7명의 자연어 명령 시나리오 24개를 분석해 필요한 필드를 정의했습니다.
  - 추출된 조건과 알림 대상을 시스템에서 처리할 수 있는 형태로 변환합니다.

- **알림 선별 전송**
  - 수신된 알림이 사용자가 설정한 조건에 해당하는지 확인합니다.
  - 조건을 충족하는 알림만 사용자에게 선별적으로 전달합니다.

- **조건 DB 및 알림 DB 관리**
  - 사용자가 설정한 알림 조건을 조건 DB에 저장합니다.
  - 수신된 알림 정보와 전송 결과를 알림 DB에 저장합니다.

- **주기적 알림 모니터링**
  - 타이머 기반으로 조건 DB와 알림 DB를 주기적으로 확인합니다.
  - 설정된 조건의 유효 시간과 알림 내용을 비교해 전송 여부를 결정합니다.

- **대화형 알림 제어 인터페이스**
  - 사용자는 자연어 명령을 입력하고 시스템이 해석한 결과를 확인할 수 있습니다.
  - 설정 완료 여부와 적용된 조건을 대화 형태로 제공합니다.

- **사용자 관리 인터페이스**
  - 사용자가 직접 설정한 알림 조건을 확인할 수 있습니다.
  - 알림 수신 기록과 선별 전송 결과를 확인할 수 있어 편의성과 투명성을 확보했습니다.

# 7. Development Workflow (개발 워크플로우)

## 7.1 문제 정의

- 스마트폰 알림 증가로 발생하는 심리적 피로감과 집중력 저하 문제 확인
- 사용자가 중요한 알림을 놓칠 수 있다는 불안감과 FoMO 문제 구체화
- 기존 알림 제어 방식의 특성과 한계를 다각도로 검토

## 7.2 기존 연구 분석

- 수동 규칙 기반 알림 설정 방식의 번거로움 분석
- 머신러닝 기반 자동 예측 방식의 부정확성 분석
- 제어 방법, 알림 특성, 사용자 상태 등 여러 관점에서 기존 연구 비교
- XMind 기반 Issue Tree를 활용해 문제와 연구 방향 구조화

## 7.3 사용자 명령 데이터 수집

- 사용자 7명을 대상으로 원하는 알림 제어 명령 수집
- 총 24개의 자연어 명령 시나리오 분석
- 명령에서 반복적으로 나타나는 조건과 알림 대상 요소 파악

## 7.4 JSON 자료구조 설계

- 시간, 장소, 활동을 조건 필드로 정의
- 앱과 키워드를 대상 필드로 정의
- 자연어 명령을 구조화하기 위한 JSON 스키마 구축

```json
[
  {
    "수신할 앱": [
      "카카오톡",
      "인스타그램"
    ],
    "수신 텍스트": [
      "게임"
    ]
  },
  {
    "조건 시작": "2025-10-28 04:28:00",
    "조건 종료": "2025-10-28 04:38:00"
  }
]
```

## 7.5 조건 추출자 개발

- ChatGPT 4o-mini와 Function Calling을 활용해 조건 추출 기능 구현
- 자연어 명령을 JSON 스키마에 맞는 구조화 데이터로 변환
- 추출된 조건과 대상 정보를 조건 DB에 저장

## 7.6 알림 관리자 개발

- Android에서 스마트폰 알림을 수신하는 기능 구현
- 수신된 알림 정보를 알림 DB에 저장
- SQL과 타이머를 활용해 조건 DB와 알림 DB를 주기적으로 비교
- 설정된 조건에 해당하는 알림만 사용자에게 전송

## 7.7 사용자 인터페이스 개발

- 사용자 자연어 명령을 입력하는 대화형 인터페이스 구현
- 시스템이 해석한 알림 조건을 사용자에게 제공
- 설정 조건과 알림 수신 기록을 확인할 수 있는 관리 화면 구현

## 7.8 논문 작성 및 발표

- 연구 배경, 시스템 구조 및 구현 결과 정리
- 제1저자로 논문 작성
- KSC 2025 학술대회 논문 발표

# 8. Project Results (프로젝트 성과)

- 사용자가 복잡한 설정 화면을 조작하지 않고 자연어만으로 알림 수신 조건을 설정할 수 있는 시스템을 구현했습니다.
- 사용자 7명의 명령 시나리오 24개를 분석해 시간·장소·활동의 조건 필드와 앱·키워드의 대상 필드를 정의했습니다.
- Function Calling을 활용해 사용자의 비정형 자연어 명령을 구조화된 JSON 데이터로 변환했습니다.
- 조건 추출자와 알림 관리자를 연계해 자연어 입력부터 조건 저장, 알림 모니터링, 선별 전송까지 이어지는 전체 파이프라인을 구현했습니다.
- SQLite를 활용해 사용자가 설정한 조건과 알림 수신 기록을 직접 확인할 수 있도록 구성했습니다.
- 기존 수동 규칙 설정 방식의 번거로움과 머신러닝 기반 자동 예측 방식의 부정확성을 균형 있게 보완했습니다.
- 연구 결과를 논문으로 발전시켜 **KSC 2025 학술대회에 논문이 채택**되었습니다.

# 9. Limitations & Future Work (한계점 및 향후 발전 방향)

- 7명의 참여자와 24개의 명령 시나리오에 한정된 사용자 데이터 규모 확대
- 다양한 표현과 복합적인 조건을 포함한 자연어 명령에 대한 검증 강화
- 사용자의 위치 정보를 활용한 장소 기반 알림 조건 추가
- Google Calendar 등 일정 정보를 활용한 사용자 맥락 이해 고도화
- 앱 사용 상태, 사용자 활동 및 시간대 정보를 결합한 조건 추출 기능 확장
- Function Calling 결과의 오류를 확인하고 수정할 수 있는 검증 단계 추가
- MCP와 연동해 캘린더, 위치, 메시지 등 외부 서비스와 연결되는 알림 에이전트로 확장
- 실제 사용자 평가를 통한 편의성, 정확성 및 알림 피로도 감소 효과 검증
